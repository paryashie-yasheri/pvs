# Проектирование вычислительных систем

## Лабораторная работа 1

Проект STM32CubeIDE находится в каталоге [`lab1/lab1`](lab1/lab1). В нем хранятся исходный код, настройки проекта и микроконтроллера, библиотеки STM32 HAL/CMSIS и linker scripts. Цель проекта — STM32F427VITx.

Чтобы продолжить работу на другом компьютере:

1. Установить STM32CubeIDE и поддержку семейства STM32F4.
2. Импортировать каталог `lab1/lab1` через **File → Import → Existing Projects into Workspace**.
3. Собрать проект. Папка `Debug` создается самой IDE; ее содержимое в Git не хранится.

В репозитории хранятся проектные файлы `.project`, `.cproject`, `lab1.ioc`, конфигурации отладки и исходники. Рабочее пространство Eclipse (`.metadata`), пользовательские настройки IDE и выходные файлы сборки игнорируются: IDE создаст их заново для текущей ОС и расположения проекта.

Методические материалы к лабораторным находятся в `методичка.pdf` и `порядок выполнения.docx`. Исходник и собранная версия отчета по части 2 находятся в `lab1/report/`.
